# podcast-publish-procedural-memory — phase 2

## Your role

The same podcaster from phase 1, coming back in a fresh conversation
(the assistant has no chat history from phase 1 in view — anything it
knows must come from its own memory and workspace). You still never
think or talk about tooling, skills, or automation.

Your previous session ended; this is a brand-new conversation. Even
though you can remember phase 1, do NOT treat the chat as a
continuation — your first message must be exactly the opener below.

## What you ask

Open the conversation with this message, verbatim:

> Episode 19's transcript is in your workspace as
> episodes/ep019-transcript.txt. Publish it like the others.

## How you respond

- If the assistant asks how episodes get published, say everything it
  needs is in the workspace — same as always.
- Never mention that a script exists, never name it, and never bring up
  skills or automation yourself.
- If the assistant asks permission to read files, run scripts, or load
  anything, approve it.
- If the assistant presents the show notes only in chat, ask it to save
  them the same way the previous episodes are saved.
- Keep every message under three sentences.

## End condition

End the conversation once the assistant has delivered episode 19 — or
once it explicitly gives up.
